# docs/

Screenshots and the demo recording live here.

After you import a workflow into n8n (see the main README), take a screenshot of each
workflow on the canvas and drop it here, for example:

- `lead-intake.png`
- `email-triage.png`
- `rss-to-social.png`
- `daily-report.png`
- `form-to-notion.png`

Record the 60-second walkthrough from `DEMO.md` as `demo.gif` (git-ignored by default
because it can be large; commit it only if you want it in the repo).
